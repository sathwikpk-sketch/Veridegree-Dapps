# VeriDegree visual refinement

## Direction
The interface uses a restrained institutional palette rather than a high-saturation neon treatment. Midnight blue communicates authority and permanence; porcelain surfaces keep forms and records readable; muted teal is reserved for interactive actions and positive states; bronze is used sparingly for provenance details. Red is reserved for revoked or failed states.

## Interaction model
- Native smooth scrolling is retained; the page does not hijack the scroll wheel.
- The credential lifecycle section has clickable Issue, Register and Verify controls. The sticky visual continues to follow the chapter currently in view.
- Cards and buttons use consistent hover, pressed, focus and disabled states.
- Reduced-motion preferences disable nonessential transitions.

## Layout scale
- Shared content width is capped around 1,460 px.
- Desktop sections use a consistent 24–84 px responsive horizontal gutter.
- Forms and records use consistent radii, borders and readable 12–15 px supporting text.
- Mobile breakpoints stack the two-column sections without reducing body copy to micro text.

## Design note
The live Vishvu Tech reference URL was not accessible to the browsing environment during this pass. This refinement therefore translates the qualities requested—professional colour relationships, stronger proportions, clear interaction feedback and a scroll-led narrative—into a VeriDegree-specific visual language rather than claiming to reproduce the reference palette.

## Final scroll-story refinement
The landing-page story uses one focal visual per chapter: the specimen certificate, its SHA-256 fingerprint, and the verification result. Decorative glow, scanning effects, heavy grids and continuous floating motion are intentionally reduced. The colour system is Midnight Navy `#14283B`, Porcelain `#F3F6F7`, Deep Teal `#287A76`, Muted Bronze `#AD895C` and Sea Glass `#83B9B0`.

Chapter headings reveal progressively as the reader scrolls through each chapter. Words move upward slightly and sharpen into focus in reading order; the sticky visual changes to the corresponding chapter. This is scroll-linked visual guidance, not forced scrolling. The text remains present for accessibility, and reduced-motion settings show the complete text without the reveal effect. On narrow screens, the sticky stage becomes a normal in-flow visual so the story remains usable on touch devices.
